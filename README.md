# Bootcamp QI Tech

Repositório dedicado ao desenvolvimento das atividades, práticas e projetos propostos ao longo do **Bootcamp da QI Tech**, reunindo implementações em equipe e exercícios individuais.

---

## 📌 Sobre o Projeto

O objetivo deste espaço é centralizar os entregáveis do programa de capacitação, documentando a evolução técnica, o fluxo de desenvolvimento e as soluções construídas durante o bootcamp.

Principais focos abordados:
* Desenvolvimento e boas práticas de engenharia de software
* Resolução de desafios práticos e estudos de caso
* Construção do projeto principal em equipe
